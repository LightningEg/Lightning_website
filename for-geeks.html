01 // System Overview

README.md
ABOUT_LIGHTNING ↗
> cat /project/mission.txt

Lightning is a local-first personal finance app built for Egypt. It brings bank accounts, wallets, budgets, savings, gold, shares and money plans into one place.

Its numbers come from a ledger. Plans stay separate from transactions. Reports calculate what the records can actually support.

Built for people who want to understand their money without handing over their bank login.

STACK_INFO v1.1 beta 1
CorePython · FastAPI
StorageSQLite · SQL migrations
InterfaceJinja2 · CSS · JS

Checkspytest · import-linter

02 // How It Works

ARCHITECTURE.md
SOURCE_TREE / lightning/ ▼
ui/FastAPI routes, Jinja templates, CSS and JavaScript
workflows/Actions that coordinate modules in one transaction
planning/Budgets, upcoming activity and cash outlook
transactions/The only writer of the real-money ledger
investments/Holdings, buys, sells and returns
reporting/Calculated views, not another source of truth
database/SQLite, migrations, backups and audit history
core/Money precision, identifiers and posting rules

Illustrative entry points, not the complete directory listing. Read the full architecture ↗

DESIGN_RULES PASS
  • Real money belongs in the ledger.
  • A plan never becomes a real transaction by itself.
  • Money uses Decimal, not floating-point math.
  • Modules use service boundaries.
  • Every change should have tests.
  • Private financial data stays out of Git.
