Contribute

Help Build Lightning. One Small Task.

Lightning is free. Help with one small task, all on GitHub in your browser, with nothing to install.

Pick a task

No GitHub account? Make one free.

Three steps

Pick It. Change It. Send It.

Everything happens on GitHub, in your browser.

  1. 1

    Pick a Task

    Open a task and type /take in the comment box at the bottom of its page. A bot gives it to you. Changed your mind? /drop gives it back.

  2. 2

    Change It in Your Browser

    Open a Codespace, an editor in your browser, and press Create codespace. The demo app opens by itself. Edit the file the task names.

    In Source Control, write a short note and press Commit to save your change, then Sync or Publish to send it to GitHub, which makes your own copy.

    Open a Codespace

  3. 3

    Ask Us to Add It

    Open a pull request, which asks us to add your change: press Compare & pull request and write Closes # with the task number.

    We review it and merge it, and the task closes itself.

If you get stuck

Ask in the Open

Every question goes on the task, except security problems.

Ask on the Task

Stuck? Write a comment on the task’s page. We answer there, where the next person can read it too.

Security Problems Stay Private

Found a way to reach someone’s data? Don’t post it. Report it privately.
